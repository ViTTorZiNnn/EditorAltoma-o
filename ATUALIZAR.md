# Atualização 0.7

1. Feche o MontaVideo anterior. Extraia o novo ZIP em uma pasta nova.
2. Execute INICIAR.bat. As conexões salvas na 0.6 são lidas do mesmo perfil Windows.
3. Use Abrir pela pasta e escolha seu projeto existente, ou crie outro.
4. Os vídeos/B-roll continuam nas pastas originais; não precisa copiá-los.
5. Para recortar, use Abrir recorte no CMD. Ao terminar, clique Atualizar cenas.
6. Confira o contexto e gere uma nova base para aplicar as melhorias desta versão.

Os recortes completos da 0.6, quando seus manifestos e arquivos continuam nos
caminhos originais, podem ser lidos sem novo recorte. Planos antigos não são
abertos automaticamente. Nenhum material do usuário é apagado pela atualização.

VoiceStudio precisa estar instalado e aberto para gerar voz. Narração já pronta
continua funcionando sem ele. Leia LEIA_PRIMEIRO.md antes de configurar as buscas.
